# 大麦 AI · Figma React UI Demo

基于 Figma 原稿实现的 375 × 812 React + TypeScript 交互演示。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 页面与交互

- 弹窗思考过程逐步展开
- 进度条与节点状态推进
- 节点 4、5、6 依次点亮
- 生成结果自动跳转
- 推荐卡片左右滑动轮播

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。
